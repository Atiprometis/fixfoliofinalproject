## About 

เป็นโปรเจคจบของ นักศึกษามหาวิทยาลัยศิลปากร โดย ชื่อเว็บว่า I LOVE TRAINING ( เรารักอบรม )

SHOWREEL :

[Watch on YouTube](https://www.youtube.com/watch?v=QaCa5hWsEaw)

เว็บไซต์ที่ รวบรวมคอร์สเรียนฝึกอาชีพสำหรับผู้รักการพัฒนาตนเอง 

จุดประสงค์ : 
1.เป็นแหล่งรวบรวมหลักสูตรวิชาชีพเพื่อง่ายต่อการค้นหางาน
2.เพื่อประชาสัมพันธ์หลักสูตรออนไลน์และออฟไลน์
3.เพื่อให้ผู้ประกอบการค้นหาคนที่ใช่ มาทำงานให้กับธุรกิจของคุณ 

ฟังก์ชั่นจะแบ่งเป็น 3 กลุ่มคือ ผู้ใช้ทั่วไป,เจ้าของกิจการธุรกิจ และ แอดมิน
ผู้ใช้ทั่วไป :
- ค้นหาคอร์​สเรียน 
- สมัครเรียน 
- สร้าง Profile และ Portfolio

เจ้าของธุรกิจ  : 
- ลงประชาสัมพันธ์คอร์สเรียน
- ค้นหาผู้สมัครงาน 

แอดมิน : 
- สร้างคอร์สประชาสัมพัธ์
- เพิ่ม,ลบ,แก้ไข,อัพเดท ​: คอร์ส,โรงเรียน
- แอดสิทธิ แอดมิน,ผู้ใช้,เจ้าของธุรกิจ
  
ภาษาที่ใช้ 
front-end: html,css,javascript,jQuery,bootstrap

back-end: php,laravel,mysql
